# Join the Storage Scale User Group

It is free to join. We hold regular meetings showcasing the latest of IBM Storage Scale (GPFS) and giving members a chance to meet IBM and talk about all things Storage Scale. Some meetings run alongside conferences that you need to register for separately.

### Mailing list

Our discussion list runs on GNU Mailman. When you join, please introduce yourself and tell us how you use, or are interested in, Storage Scale.

### Discord

We use Discord for day-to-day community chat, questions and announcements. Come and say hello.

If the invite is not working and you would like to join, email
[systems@gpfsug.org](mailto:systems@gpfsug.org)or

[chair@gpfsug.org](mailto:chair@gpfsug.org).

**Storage Scale User Group**
